# Build a Search Campaign

Read the approved keyword architecture, client profile, current account snapshot, `config/agency.yaml`, and the preserved campaign SOP.

Do not begin until the current work order passes validation and the observed exact child account name and ID match it.

Before any write, show:

- Exact child account name, 10-digit child customer ID, vertical, and exact service.
- Campaign names and daily/monthly budgets.
- Locations, Presence option, exclusions, languages, and schedule.
- Bidding and primary conversions.
- Ad groups, Phrase + Exact keywords, negatives, two RSAs per group, assets, and final URLs.
- Exact count of resources to create.

Generate a campaign plan and run the validators. Obtain the plan fingerprint approval. Create all resources paused, read them back, compare against the plan, and write a receipt. Do not enable delivery. Do not sweep-exclude every other country unless the client explicitly requires it and the rationale is documented.
