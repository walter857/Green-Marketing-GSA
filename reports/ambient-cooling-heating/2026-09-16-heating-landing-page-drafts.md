# Technical requirements — ALL THREE PAGES

These are launch blockers. They exist because the five live paid pages fail every one of them
today (see `AMB-0915-LP-1 / 5354E1E2F576`).

### Forms and DOM
- **One rendered Gravity Form instance per page.** Every other CTA scrolls to it via an anchor.
  If a second instance is unavoidable, **every** form, wrapper, field, label, validation and
  confirmation ID must be unique.
- **Unique DOM IDs page-wide.** Zero duplicates.
- **Unique form IDs**, unique success-state IDs.
- One submission ⇒ **one** lead record, **one** GTM form-success event, **one** Google Ads
  conversion. A reload or back-button must not count another.
- **Do not populate the Gravity Forms honeypot.** Its index is not stable across sites and its
  label rotates per render — identify it at build time, never by assumption.

### Attribution — cache-safe, the critical requirement
- **Do not populate visitor-specific values server-side.** The hidden attribution inputs must ship
  with `value=""` in the cacheable document.
- Populate **client-side after load** from `location.search`; fall back to a first-party cookie
  scoped to the registrable domain only when the current URL lacks the parameter; **never** from a
  cached value. Last-touch wins when the current URL carries a click ID.
- A direct visit with no parameters and no cookie must leave the fields **empty**, never inherit
  another visitor's data.
- Capture and preserve through submission: **GCLID · GBRAID · WBRAID · utm_source · utm_medium ·
  utm_campaign · utm_term · utm_content · landing_url · first_landing_url · campaign · ad_group ·
  keyword · device · unique lead ID · consent state**.
- If client-side capture cannot ship immediately, **exclude these URLs from full-page dynamic
  caching** as a temporary fallback. A cache purge alone is not a fix.

### Phones
- Display **(410) 705-6354** everywhere.
- Every clickable telephone link: **`tel:+14107056354`** (E.164). No `tel:4107056354`, no
  `tel:(410) 705-6354`.
- **`410-914-1456` must not appear anywhere in the DOM**, including hidden elements.
- **`410-761-0932` must never appear publicly** in rendered text or HTML source.
- WhatConverts DNI must not replace the paid number with an unapproved number.

### Preserve
GTM `GTM-PQTPQ436` · Google Ads `AW-11155434808` · GA4 `G-9X9ZHNCRWF` · the WhatConverts script
and all number routing · `noindex, nofollow` · Privacy and Terms links.

### Add
Self-referencing **canonical** URL on each page.

### Must not exist
Fake countdown · nonexistent offer · developer instructions rendered as public body copy · empty
gallery · duplicate Gravity Forms rendering · any barred claim.
